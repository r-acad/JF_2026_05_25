JFEM-Boxer

A Study (.wingfem.json) contains parameters, load cases, constraints, embedded references, 2D drawings, display settings and timestamped notes. Solver results are separate. Save Study updates the linked file; the first save chooses its filename and folder. Save Study as… selects a new destination with the browser picker or the local operating-system dialog. If neither is available, a browser download is offered explicitly. Orange means unsaved definition changes; green means the definition is saved. Camera and display changes leave this indicator unchanged, but their current settings are included when you save. TOML stores model parameters, constraints, load cases, all loaded reference placements and cache paths, and the Plan view background image. Saving caches unlinked references without overwriting the server input. Reference paths depend on this server's input folder; use Save Study to move embedded geometry, all display settings, other images and notes between computers. Import validates before replacing the current Study.
