Connecting to Study…

These are derivatives of the selected scalar response, not a local stress or nodal sensitivity field. A panel row differentiates one panel property. Shared default variables remain separate and must not be summed with local panel derivatives.

The panel grid uses recorded physical stringer and rib-bay identities. P numbers come from the run’s property IDs. Matching current geometry can supply empty panel cells; a historical run from another topology uses only recorded panels. Each segment has its own entry. The Property selector lists the properties requested or returned for the chosen skin, with shell thickness first. For other components it also includes available dimensions recorded with the run. A result belongs to one panel/property combination: selecting shell thickness does not select that panel’s stringer dimensions. Cells distinguish properties not selected in the recorded run from selected properties whose result is missing or pending. Failed or unavailable returned derivatives retain their reason and are never zero-filled. Current Study selections do not change a saved run.

The Group selector also includes spar webs, spar caps, rib webs, rib stiffeners, leading-edge skins and leading-edge ribs. Local component variables use their recorded rib or rib-bay keys, matching the editable component property tables. Shared defaults and materials are listed separately: each number is the full derivative of that shared variable over all affected elements, not an independent derivative at each rib. A material can appear in several groups while retaining the same full derivative; do not sum those copies. Imported or older rows without recognized component ownership remain available in All properties and Other properties. Groups without recorded geometry or property ownership are greyed out. A group can show an entire grid of Not selected cells when the run requested only its shared default. The counter separates local result rows from shared result rows. In Analysis → Sensitivity, selecting a component family selects independent dimensions at every active location, including overridden properties. Older shared component selections are converted when model properties are refreshed. Spar webs, the four spar caps and leading-edge skins have one property per rib bay; rib webs, stiffeners and leading-edge ribs have one property per physical rib. You can deselect individual locations. Add component variables selects all available local dimensions while preserving other selections. Click Run sensitivity to calculate their separate derivatives; selections alone never start an analysis, and saved results are never filled from a shared derivative.

df/dp has response units divided by property units. The normalized derivative (p/f) × df/dp is dimensionless: for a small percentage property change it estimates the response’s relative percentage change. It is undefined for a zero baseline. Signs refer to the signed recorded scalar response. These are derivatives, not new solved load cases. Operator samples used during derivative assembly are not perturbed response values.

Automatic color limits are the actual finite minimum and maximum of the displayed table, for the chosen structural group, property, quantity and filter. There is no symmetric expansion or forced zero bound. The Color scale selector changes only this table. For Signed red (-) / blue (+), negative values are red and positive values are blue. One-sided ranges use light to dark shades of the corresponding color. A range containing both signs has a neutral stop at zero’s true position. Equal values have one uniform shade. Raw derivatives with different units have separate labeled scales; normalized values share one dimensionless scale. Missing or failed values are excluded. Shading changes neither the data nor the viewport palette or its manual limits.

All properties includes every result row; Other properties excludes panel-local variables. Filter those lists by property name or ID. Displayed numbers have at most five significant digits. Units are shown with the color scales and in value tooltips instead of repeating under every panel cell. Stress responses with known Pa, kPa, MPa or GPa units are displayed in MPa (derivatives in MPa per recorded property unit). Unspecified source units are preserved without an assumed conversion. CSV retains canonical recorded units and exports the currently selected table and filter with full-precision raw and normalized values, IDs, units and status. This tab is read-only. Light/dark theme is a browser preference shared with detached property tables and does not modify the Study.

Each value is for the chosen structural group and property in the recorded run. The Property selector shows result counts. “Not selected” refers to this run, not the current Study checkboxes.
