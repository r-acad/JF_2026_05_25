Panel properties

Connecting to Study…

This table is a live editor for the Study window. Edits update that Study and its normal automatic-mesh workflow. Save Study or Save TOML in the Study window to save your changes. Keep the Study window open.

Rows are physical stringer numbers in ascending order; columns are physical rib bays. P labels match the 3D panel IDs. A cell can contain several segments separated by runouts. Empty cells have no normal-stringer panel. Choose one property above to edit its values across the table. Pale placeholder values are inherited from shared defaults; an entered value is an explicit override. Clear an input or choose Inherit to restore its default. Lengths are displayed in mm and saved in metres.

Sandwich panels use face/core/face, with total thickness = twice each face plus core. Monolithic thickness and material are dormant for sandwich panels. Face/core settings are dormant for monolithic panels. Materials are selected from the Study library; core models are effective isotropic placeholders, not strength or damage models. T dimensions must satisfy tf < h and tw < b.

Panel overrides are attached to the generated rib/stringer layout. A geometry change can invalidate them; the server will reject an obsolete layout instead of silently reassigning properties. Reset all panel overrides to return to shared defaults if the layout changes. Reset affects both tables and can be undone by reloading a saved Study.

Create FEM in the Study window to populate this table.
