Connecting to Study…

These are derivatives of the selected scalar response, not a local stress or nodal sensitivity field. A panel row differentiates one panel property. Shared default variables remain separate and must not be summed with local panel derivatives.

The panel grid uses recorded physical stringer and rib-bay identities. P numbers come from the run’s property IDs. Matching current geometry can supply empty panel cells; a historical run from another topology uses only recorded panels. Each segment has its own entry. The Property selector lists the properties requested or returned for the chosen skin, with shell thickness first. A result belongs to one panel/property combination: selecting shell thickness does not select that panel’s stringer dimensions. Cells distinguish properties not selected in the recorded run from selected properties whose result is missing or pending. Failed or unavailable returned derivatives retain their reason and are never zero-filled. Current Study selections do not change a saved run.

df/dp has response units divided by property units. The normalized derivative (p/f) × df/dp is dimensionless: for a small percentage property change it estimates the response’s relative percentage change. It is undefined for a zero baseline. Signs refer to the signed recorded scalar response. These are derivatives, not new solved load cases. Operator samples used during derivative assembly are not perturbed response values.

Automatic color limits are the actual finite minimum and maximum of the displayed table, for the chosen skin, property, quantity and filter. There is no symmetric expansion or forced zero bound. The Color scale selector changes only this table. For Signed blue / orange, negative-only ranges run from darker to lighter blue; positive-only ranges from lighter to darker orange. A range containing both signs has a neutral stop at zero’s true position. Equal values have one uniform shade. Raw derivatives with different units have separate labeled scales; normalized values share one dimensionless scale. Missing or failed values are excluded. Shading changes neither the data nor the viewport palette or its manual limits.

All properties includes every result row; Other properties excludes panel-local variables. Filter those lists by property name or ID. CSV exports the currently selected table and filter with full-precision raw and normalized values, IDs, units and status. This tab is read-only. Light/dark theme is a browser preference shared with detached property tables and does not modify the Study.

Each value is for the chosen skin and property in the recorded run. The Property selector shows result counts. “Not selected” refers to this run, not the current Study checkboxes.
